پروژه داشبورد هوشمند پیش‌بینی قیمت خودرو
==========================================

این نسخه رابط HTML/CSS/JavaScript را با بک‌اند Python و مدل‌های واقعی یادگیری ماشین متصل می‌کند.

ساختار:
- app.py: سرور Flask و API
- main.py: کد اصلی تحلیل و آموزش مدل‌ها
- train_models.py: آموزش و ذخیره مدل‌های برتر
- cars_dataset.csv: دیتاست آموزشی مصنوعی ۳۰۰ رکوردی
- templates/index.html: صفحه داشبورد
- static/css/style.css: ظاهر و واکنش‌گرایی
- static/js/app.js: دریافت داده‌ها و ارسال درخواست پیش‌بینی
- models/: مدل‌های آموزش‌دیده و اطلاعات داشبورد (پس از اولین اجرا ساخته می‌شود)

راه‌اندازی در ویندوز و VS Code:
1) فایل ZIP را Extract کنید.
2) پوشه car_dashboard_project را در VS Code باز کنید.
3) در ترمینال VS Code اجرا کنید:
   python -m venv .venv
4) فعال‌سازی محیط:
   PowerShell:
   .\.venv\Scripts\Activate.ps1
   اگر خطای مجوز گرفتید، فقط برای همین پنجره:
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   سپس دستور فعال‌سازی را دوباره اجرا کنید.
5) نصب کتابخانه‌ها:
   python -m pip install -r requirements.txt
6) اجرای برنامه:
   python app.py
7) در مرورگر باز کنید:
   http://127.0.0.1:5000

نکات:
- در اولین اجرا، اگر فایل مدل‌ها وجود نداشته باشد، برنامه آن‌ها را از روی CSV آموزش می‌دهد؛ ممکن است چند لحظه طول بکشد.
- بعد از آموزش، مدل‌ها در پوشه models ذخیره می‌شوند و در اجراهای بعدی دوباره آموزش داده نمی‌شوند.
- برای آموزش مجدد پس از تغییر دیتاست، پوشه models را حذف کنید و app.py را دوباره اجرا کنید یا python train_models.py را اجرا کنید.
- پیش‌بینی قیمت و دسته‌بندی از دو Pipeline آموزش‌دیده مستقل استفاده می‌کنند.
- ستون Price فقط برای آموزش رگرسیون و ساخت برچسب کلاس استفاده شده و به عنوان ورودی مدل دسته‌بندی استفاده نمی‌شود.
- داده‌های CSV مصنوعی و آموزشی‌اند؛ بنابراین خروجی قیمت را نباید قیمت قطعی بازار دانست.


تصاویر خودرو: برای ۲۰ مدل موجود در دیتاست، تصاویر استودیویی نمونه به‌صورت خودکار در لیست خودروها و کارت‌های مقایسه نمایش داده می‌شوند. این تصاویر صرفاً نمایشی/تولیدی هستند و لزوماً تصویر دقیق همان تیپ یا سال ساخت نیستند.
